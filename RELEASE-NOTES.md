# Ember 0.5.5

- Mod cards now show category tags and package status, including deprecated and pinned labels.
- Added **Show deprecated** to include deprecated packages in catalog searches.
- Deprecated packages show a clear warning in their details. Labels also appear in favorites and installed mods.
- Catalog searches and additional results now use the simpler **Loading…** message.

Installed clients receive this update through **Settings → Update client** or the automatic startup check. Portable users can download a replacement from the [latest release](https://github.com/Ember-Mod-Loader/Ember/releases/latest).

Both Windows builds are unsigned. Existing profiles and preferences are preserved.
