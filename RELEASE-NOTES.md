# Ember 0.5.4

- Ember now checks for client updates on its branded loading screen before opening the workspace.
- Available updates show download progress, installation status, and a clear message that Ember will reopen automatically.
- Startup waits for the update handoff instead of briefly opening the library before restarting.
- Failed or stalled checks let the workspace open. Updates blocked by a running game remain available in Settings.
- Existing update verification, restart safeguards, profiles, and preferences are preserved.

Installed clients receive this update through **Settings → Update client** or the automatic startup check. Portable users can download a replacement from the [latest release](https://github.com/Ember-Mod-Loader/Ember/releases/latest).

Both Windows builds are unsigned. Existing profiles and preferences are preserved.
